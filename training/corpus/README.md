# 训练资料

[训练语料目录 CSV](catalog.csv) 收录实际盘点的 68 项来源，包含年度、题号、论文编号、用途、完整性记录和官方入口。部分旧材料只有官方分类入口，CSV 的「链接层级」标明了粒度。对照时可用来源 ID 串起盘点、论文矩阵和案例讨论。

## 仓库内的训练材料

- [训练语料综合笔记](../evidence/analysis/lean/b_training_synthesis.md)归纳各年代的子问题依赖、路线差异和验证方式。
- [B 题建模契约](../evidence/analysis/lean/b_training_problem_contracts.json)保留问题拆解、输入输出、约束和证据定位。
- [19 篇训练论文对照矩阵](../evidence/analysis/lean/b_training_source_matrix.json)包含深读标记、覆盖范围、方法和可迁移线索。
- [语料审计](../evidence/planning/corpus_audit.md)与[文本提取验收](../evidence/preprocessing/batch_qa_report.md)记录源材料完整性、OCR 局限和盲测隔离。
- [训练练习和复验](../practice.md)含运行方式、合成数据与对照概念。
