# 配置与运行策略联合设计

这不是独立题型分类。用于同一任务同时存在慢变量（机器工序配置、布局）与快变量（实时派工）的情形；可与状态压缩、有限前瞻组合。

## 解法核心
只优化派工而固定设备配置，可能在错误的产能结构上反复搜索。先写 J(c,pi;omega)：配置 c、策略 pi、外生场景 omega 的统一评价器。规模允许时枚举合法 c，逐配置比较 pi；结构较大时外层搜索配置，内层在同一预算下优化策略。保留配置与策略之间的相互作用，不允许分别排名后直接拼接。
不同配置下内层搜索误差可能不同：同一时间预算不自动保证公平，把候选改善曲线、可行下界/上界及重启差异同时保存。未经证明，不把嵌套求解称为分解后的全局最优。

## 可落地流程
1. 列出能在班次前决定的 c 和运行时才能决定的 a_t，建立事件驱动状态转移；维护剩余加工、位置、请求与工序状态。
2. 用瓶颈产能界排除明显不可能更优的配置，仅在界有证明时硬剪枝；启发式评分用于排序。
3. 同一配置至少比较一个真实可行规则与一个针对等待/搬运瓶颈的策略。计算到达时是否可服务，而非仅看出发时设备状态。
4. 有故障时共用可复现的外生事件场景，报告策略差值，不靠单次随机运行选赢家。
5. 保存配置、动作轨迹、完工数、等待/搬运、边界时刻和违规明细。

## 转移条件与失效边界
外层配置必须真实可决策；配置无法改动的题不做外层优化。主动移动、清洗与加工并行需题设支持。故障改变配置含义时不能共享错误的状态转移。

## 证据与验证
训练论文 2018 B217 的可读片段中，作者联合遍历工序布局和多种派工原则（原派生文本行41–43、819–820），不是只使用 FIFO。作者近最优声明未经本次复现；不可迁移为保证。
验证：小规模配置×策略全枚举对照；事件轨迹独立重放；消融“固定配置”与“联合选择”。核心收益衡量是可行产出差、搜索预算和瓶颈变化，而非是否用了复杂算法。
