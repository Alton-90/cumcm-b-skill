# 用几何消元缩减反演，再处理身份歧义与控制

适用于前向关系存在可利用的几何结构；通用非线性最小二乘保留为噪声修正/对照，不默认从黑箱优化开始。

## 解法核心
把角度/距离观测改写为轨迹集合，先用交点、对称性、不变量或解析消元降低未知维数，再筛选物理解。例：两个不同圆共有已知点P时，另一交点是P关于圆心连线的镜像；相切时两点重合，同心/重合圆不能提供唯一新点。必须核验P在两圆上，不能对不满足条件的含噪数据硬用公式。
方位观测还可能有方向、补角和身份歧义。连续位置求解不能替代发射源身份辨识：先生成离散身份假设，再用全部可见角约束、可行区域及先验边界排除，保留无法区分的解。

## 从定位到调整
估计位置与选择下一组观测/调整动作是不同问题。改善某个参考点可能提高后续定位质量，即时全队误差降幅不是唯一指标。有限前瞻可比较即时误差、后续可观测性与动作成本，但评价器需要适配实际要求。观测无噪声、发射源理想、执行无误差分别标注，不相互代替。

## 实现与验证
接口：几何观测→候选轨迹/交点→身份筛选→物理参数→动作→新观测。解析结果与直接约束残差交叉检查，噪声时用有界估计修正而非伪装精确交点。
测试旋转平移不变性、镜像多解、相切、同心、接近退化和有噪声情形；输出候选解集合与误差传播，不能仅“成功收敛”。脚本 known_circle_partner 提供有明确前提的反射内核，不是完整纯方位定位器。
