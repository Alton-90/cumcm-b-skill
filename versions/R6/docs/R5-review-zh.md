# R5 通用解法强化候选版

基于 R4，按用户反馈从基础算法目录改为条件性解法设计。原 R4 压缩包保留，本版未安装到全局技能目录。

## 核心变化
- 配置与实时策略联合评价，避免固定错误配置后只优化调度。
- 保留决策机会的状态压缩与有限前瞻，区分等价变换和启发式。
- 实验混杂、联合响应和能区分竞争模型的追加实验。
- 几何消元、身份歧义筛选和定位到调整的分层。
- 不变量方向、活动约束递推与真实联合覆盖。
- 回收质量信息、返工闭环和参数变化下的策略切换。

入口是 `.codex/skills/method-selector/references/solution-playbooks.md`；Claude和插件副本含相同资源。新增指南按需加载，已接入方法筛选、代码计划、Python/MATLAB生成与审查、稳健性检查，不新增人工确认轮次。

## 已验证及限制
四个窄数学内核完成17项合成机制/反例测试；七个修改技能通过quick_validate；三份技能树逐字节一致。结果见 R5-validation.json、R5-skill-validation.json、R5-build-checks.json。
未完成整题性能对照、独立模型行为验证或MATLAB执行验证。配置联合搜索、宏图压缩和覆盖递推提供条件化实现设计，未提供完整求解器。示例不能作为真实赛题baseline，不能据此宣称国赛分数提升。

## 证据来源
来源说明与派生文本哈希位于技能的 references/method-design-evidence.md。论文设计、作者结论、本次扩展和实际测试严格区分。对论文中天气假设、近最优声明、端点稳健性等未无条件采纳。
