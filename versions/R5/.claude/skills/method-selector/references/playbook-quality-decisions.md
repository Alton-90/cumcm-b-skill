# 质量状态追踪、返工闭环与策略切换

适用于装配、检测、拆解再利用的闭环决策。单件一次检测的期望利润不能代表多阶段题的核心。

## 解法核心
状态不仅记录库存数量，还记录质量信息：已检合格、未检、来自失败成品的回收件、所在装配层级。观察到成品失败会改变对零件质量的条件分布；回收件不能自动重置为新购件的独立不良率。必要时跟踪联合信念，状态压缩必须保留后续决策所需信息。
固定策略下，可把返工写为暂态转移矩阵Q与每步净收益r，v=r+Qv。只有闭环最终吸收且期望累计收益存在时才能解；常用有限状态条件是谱半径rho(Q)<1。不能无限循环到“看起来利润稳定”就当作收敛证明。数值截断需给剩余误差或明确限制。
小策略空间先枚举每种完整策略并计算价值，较大空间再搜索。采购、检测、装配、退换、拆解和残值的记账时点一致，避免循环重复算收入或漏算替换成本。

## 不确定性与策略切换
将抽样信息传入同一策略价值评价器，绘制不同缺陷率/成本下赢家与后悔值。只计算区间两端不足以证明整个区间稳健，除非已证明差值单调或给出保守界。把离散策略插值为检测概率是模型变化，数值优化恰好落在0/1不能证明一般最优解必为二元。

## 实现与验证
输入装配图、质量信息状态、动作、转移与成本、参数证据；输出策略、状态价值、吸收/收敛证据、参数切换区域。单状态内核 renewal_value(r,q)=r/(1-q) 只提供可手算闭环参照；多状态需实际矩阵/图求解。
测试无返工、必吸收、永不吸收、一次与反复循环成本及条件质量更新；小例枚举与仿真对照。报告方法计算精度与参数不确定性，二者不可混用。
